# POWUI

Cross-platform, comic-inspired UI library — React + React Native, one design language via shared tokens.

## Packages

- `@powui/tokens` — design tokens (color, theme, spacing, typography, motion, ...)
- `@powui/core` — platform-independent types/utils, no React
- `@powui/react`, `@powui/react-native` — components + `configure`/`useStyles`
- `@powui/icons` — shared icons

## Commands

```
pnpm verify   # test, format check, lint, typecheck
pnpm build
pnpm dev
```

See `agents/` for architecture, tokens, theme, and status details.
